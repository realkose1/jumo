# 봉은사 메타버스

서울 강남 빌딩 숲 한가운데 있는 봉은사 마당을 여러 사람이 함께 거니는 3D 공간입니다.
주모 앱의 '응원 주막' 엔진(three.js 화면, Cloudflare Durable Object 실시간 서버)을 가져와 주막 전용 코드를 덜어 내고 봉은사 공간을 얹었습니다.

## 공간

- 진여문으로 들어와 법왕루 아래를 지나면 연등이 걸린 앞마당과 삼층석탑, 석등, 대웅전이 나옵니다. 대웅전 뒤에는 판전이 있습니다.
- 서쪽에는 미륵대불과 지장전이, 동쪽에는 범종각과 선불당이 있습니다. 담장 너머로 강남의 빌딩이 보입니다.
- 하늘은 서울의 실제 해 위치를 따라 낮과 밤이 바뀝니다. 밤에는 연등, 석등, 빌딩 창이 켜집니다.
- 정시마다 범종이 세 번 울립니다(새벽 4시와 저녁 6시 예불 때는 일곱 번). 서버 시각에 맞춰 모두가 같은 순간에 듣습니다.
- 동작은 세 가지입니다. 합장(가까운 사람에게 인사 알림), 목탁, 연등 띄우기(여섯 가지 색 등이 하늘로 오릅니다).
- 앉을 수 있는 자리는 대웅전 앞 방석 12개, 미륵대불 앞 방석 8개, 범종각 옆 나무 의자 6개입니다.
- 옷은 템플스테이 수련복이고, 머리 모양과 조끼가 네 가지입니다.
- 소리는 모두 WebAudio로 만듭니다. 솔바람, 풍경, 산새, 도시 소음, 싱잉볼, 목탁, 범종을 냅니다.

## 실행

```sh
cd server && npm install && npm run dev   # 실시간 서버 ws://localhost:8797
cd web && npm install && npm run dev      # 화면 http://localhost:5180
```

- 서버 없이 화면만 띄우면 혼자 모드로 돕니다.
- 주소 뒤에 `?timeOffset=분`을 붙이면 시간을 당겨 낮과 밤을 볼 수 있습니다. 예: `/bongeunsa?timeOffset=600`
- `?room=2`처럼 방을 고를 수도 있습니다.
- 시험: `web`에서 `npm test`, `npm run typecheck`. `server`에서 `npm test`.

## 구조

- `shared/spaces/bongeunsa.ts`: 서버와 화면이 함께 보는 공간 데이터입니다(정원 40명, 방 5개에서 최대 20개, 자리 id, 동작 id).
- `web/src/spaces/bongeunsa/`: 3D 장면입니다.
  - `layout.ts`: 배치와 걷기 범위
  - `build.ts`: 건물
  - `roof.ts`: 한옥 지붕
  - `scene.ts`: 하늘, 연등, 범종, 효과
  - `sound.ts`: 소리
  - `outfit.ts`: 옷
- 엔진 설명은 `docs/engine.md`, 화면 디자인 규칙은 `docs/design.md`에 있습니다.
- 엔진에 더한 것:
  - 몸짓 `bow`, `tap`, `offer`
  - `SpaceDefinition.attach`: 엔진 이벤트를 장면 효과에 잇습니다.
  - `SceneHandle.cameraObstacles`: 카메라가 건물을 뚫고 들어가지 않게 합니다.

건물 배치와 거리는 실제 봉은사를 참고해 줄였고, 모든 3D는 코드로 만든 기본 도형입니다(외부 3D 파일 없음).
