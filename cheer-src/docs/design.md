# 공통 UI 톤

세 공간이 같이 쓰는 화면(동작 버튼, 설정 창, 알림, 로딩)의 모양을 정하는 문서다. 2026-10-31 결정(`docs/decisions.md` 11번)으로, 어두운 유리판 대신 밝고 정돈된 톤을 기본으로 한다. 코드는 `web/src/ui/ui.css`에 있고, 공간 정의의 `theme`(`SpaceUiTheme`)로 공간마다 일부를 덮어쓴다.

## 톤

- 면: 크림과 연회색 반투명 면. 뒤의 3D 장면이 비치되, 글자가 읽히는 만큼은 충분히 덮는다.
- 글자: 검정 계열(`#26282B`), 보조 글자는 진한 회색(`#52565B`).
- 선: 얇은 연회색 1px. 면을 둘러싸는 옅은 테두리 역할도 한다.
- 그림자: 크고 부드럽게, 낮은 농도로. 면이 장면에서 살짝 떠 보이게만 한다.
- 강조색: 공간마다 하나. 한 화면에서 가장 강한 색이어야 하므로 여러 곳에 흩뿌리지 않는다.
- 아이콘: 직접 그린 선 그림이고 선 색은 `currentColor`라서 글자색을 따른다.

## 공간별 강조색

| 공간 | 강조색(`accent`) | 그 위 글자(`accentInk`) | 비고 |
|---|---|---|---|
| 기본(시험 방 포함) | `#4F5B66` | `#FFFFFF` | 중립적인 슬레이트. 공간이 덮어쓰지 않으면 이 값 |
| 열람실 | 미정 | 미정 | 열람실 장면 분위기를 정할 때 같이 정한다 |
| 빨래방 | `#C8343A` | `#FFFFFF` | 장면 속 빨간 문손잡이와 같은 색(`docs/spaces/laundromat.md` 분위기 기준) |
| 고궁 | 미정 | 미정 | 고궁 장면 분위기를 정할 때 같이 정한다 |

새 강조색을 정할 때는 아래 대비 기준을 확인한다. 시험 방(`test-room`)은 `theme`를 넣지 않고 기본값으로 둔다.

## CSS 변수 (--qs-*)

`.qs-ui`에 기본값이 있고, 공간 정의의 `theme` 값이 있으면 같은 이름의 변수로 덮어쓴다(`theme` 키 `accentInk`는 `--qs-accent-ink`가 된다).

### 공간이 덮어쓸 수 있는 값 (theme 키가 있다)

| 변수 | theme 키 | 기본값 | 쓰임 |
|---|---|---|---|
| `--qs-accent` | `accent` | `#4f5b66` | 인사 버튼 면, 켜진 스위치, 슬라이더와 진행 막대, 선택 표시, 포커스 고리, 작은 이름표 |
| `--qs-accent-ink` | `accentInk` | `#ffffff` | 강조색 면 위의 글자와 그림 |
| `--qs-surface` | `surface` | `rgba(246, 243, 237, 0.86)` | 동작 버튼 막대, 설정 버튼, 알림 한 줄 |
| `--qs-surface-solid` | `surfaceSolid` | `rgba(246, 243, 237, 0.97)` | 블러를 못 쓰는 브라우저의 면, 설정 버튼을 가리킬 때 |
| `--qs-surface-strong` | `surfaceStrong` | `rgba(248, 246, 241, 0.94)` | 설정 창 같은 큰 면 |
| `--qs-ink` | `ink` | `#26282b` | 글자, 아이콘 |
| `--qs-ink-soft` | `inkSoft` | `#52565b` | 보조 글자, 설명, 숫자 표시 |
| `--qs-line` | `line` | `rgba(38, 40, 43, 0.14)` | 면의 테두리, 구분선 |
| `--qs-radius` | `radius` | `18px` | 버튼과 카드의 모서리 |
| `--qs-blur` | `blur` | `14px` | 면 뒤 배경 블러(설정 창은 24px) |

### 기본 모양 (theme 키가 없다)

| 변수 | 기본값 | 쓰임 |
|---|---|---|
| `--qs-shadow` | `0 6px 24px rgba(38, 40, 43, 0.14), 0 1px 2px rgba(38, 40, 43, 0.1)` | 면의 부드러운 그림자 |
| `--qs-hit` | `44px` | 누르는 영역의 최소 크기 |
| `--qs-ease` | `cubic-bezier(0.22, 0.7, 0.2, 1)` | 움직임의 가속 곡선 |
| `--qs-fill` | `color-mix(in srgb, var(--qs-ink) 6%, transparent)` | 가볍게 눌린 면, 안내 문구 바탕 |
| `--qs-fill-strong` | `color-mix(in srgb, var(--qs-ink) 11%, transparent)` | 아이콘 버튼 눌림, 진행 막대 바탕 |
| `--qs-track` | `color-mix(in srgb, var(--qs-ink) 55%, transparent)` | 꺼진 스위치, 슬라이더 빈 구간, 라디오 테두리 |
| `--qs-card` | `rgba(255, 255, 255, 0.58)` | 설정 창 안의 카드(소리, 자료, 조작 목록), 보조 버튼 |
| `--qs-card-hover` | `rgba(255, 255, 255, 0.88)` | 카드 위에 올렸을 때, 선택된 탭 |
| `--qs-scrim` | `rgba(38, 40, 43, 0.4)` | 설정 창 뒤를 덮는 막 |
| `--qs-loading-bg` | `rgba(246, 243, 237, 0.92)` | 로딩 화면 바탕(크림) |

`--qs-fill`, `--qs-fill-strong`, `--qs-track`은 `--qs-ink`에서 만들어지므로 공간이 `ink`를 바꾸면 같이 따라온다.

## 어두운 장면 위에서도 읽히는 규칙

면 뒤의 장면은 낮의 밝은 빨래방일 수도, 밤이나 지금의 회색 시험 방(`#1c1c1f`)일 수도 있다. 면은 어떤 장면 위에서도 아래 기준을 지킨다.

- 글자와 보조 글자는 면 뒤가 완전한 검정이어도 4.5:1 이상이어야 한다. 그래서 기본 면 불투명도의 하한은 다음과 같다.
  - 일반 면(`surface`): 0.86 이상
  - 설정 창(`surfaceStrong`): 0.94 이상
  - 로딩 화면(`loading-bg`): 0.92 이상
- 공간이 `surface`를 바꿀 때도 이 하한을 지킨다. 밝은 면을 더 투명하게 만들면 어두운 장면에서 보조 글자가 먼저 무너진다.
- 큰 면(설정 창)은 더 불투명하게, 작은 면(버튼 막대)은 장면이 살짝 비치게 한다.
- 면에는 항상 1px 연회색 테두리와 부드러운 그림자를 둔다. 밝은 면이 밝은 장면 위에 놓일 때 경계를 만들어 주는 것이 이 둘이다.
- 강조색은 면 위에서 글자색으로 직접 쓰지 않는다. 링크는 강조색 70%에 글자색 30%를 섞어 어둡게 만든 색을 쓰고, 작은 이름표는 강조색 면에 `accent-ink` 글자로 만든다.
- 인사 버튼은 강조색 면에 `accent-ink` 글자와 그림으로 구분한다. 장면 색과 상관없이 대비가 `accent`와 `accentInk`의 대비로만 정해진다.

### 대비 기준과 현재 값

| 항목 | 기준 | 기본 슬레이트 | 빨래방 빨강 |
|---|---|---|---|
| 글자(`ink`)와 일반 면, 검정 장면 위 | 4.5:1 | 9.7:1 | 9.7:1 |
| 보조 글자(`ink-soft`)와 일반 면, 검정 장면 위 | 4.5:1 | 4.9:1 | 4.9:1 |
| 보조 글자와 설정 창 면, 검정 장면 위 | 4.5:1 | 6.0:1 | 6.0:1 |
| 보조 글자와 로딩 바탕, 검정 장면 위 | 4.5:1 | 5.6:1 | 5.6:1 |
| `accent-ink`와 `accent`(인사 버튼, 이름표) | 4.5:1 | 6.9:1 | 5.2:1 |
| 링크색(강조색 70% + 글자색 30%)과 일반 면, 검정 장면 위 | 4.5:1 | 5.8:1 | 4.9:1 |
| `accent`와 일반 면(포커스 고리, 켜진 스위치), 검정 장면 위 | 3:1 | 4.6:1 | 3.4:1 |
| 꺼진 스위치와 슬라이더 빈 구간(`track`)과 일반 면 | 3:1 | 3.1:1 | 3.1:1 |

수치는 WCAG 상대 휘도로 계산한 값이고, 장면이 흰색이나 회색이면 모두 더 높아진다. 새 강조색은 `accent`와 `accentInk`가 4.5:1 이상, `accent`와 일반 면이 3:1 이상이어야 한다.

## 로딩 화면

- 바탕은 크림(`--qs-loading-bg`)이고, 3D 장면이 흐리게 비친다.
- 진행 막대는 강조색, 막대 바탕은 `--qs-fill-strong`.
- 손장난 버튼은 흰 카드 면에 부드러운 그림자, 움직이는 점은 강조색이다.
- 준비가 끝나면 크림 바탕이 투명해지며 걷힌다. 움직임 줄이기가 켜져 있으면 바로 걷는다.

## 접근성과 움직임

- 누르는 영역은 `--qs-hit`(44px) 이상이다.
- 움직임 줄이기(기기 설정 또는 설정 창의 선택)가 켜지면 UI의 전환과 애니메이션이 사실상 멈춘다(`.qs-reduced`).
- 휴대폰(폭 560px 이하)에서는 설정 창이 아래에서 올라오는 시트가 된다.
- 설정 창이 열려 있는 동안 뒤쪽은 키보드와 화면 읽기에서 빠지고, `Esc`로 닫고, 포커스는 창 안에 머문다.
- 화면 문구는 한국어 '~해요' 체이고, 고궁만 영어를 함께 보여준다.
